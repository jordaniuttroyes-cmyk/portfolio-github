SAÉ 105 BUT MMI

La Gimsothèque

Dans le cadre de la SAÉ 105 de première année de BUT MMI, il m'a été demandé de concevoir un site web entièrement dédié à un artiste de mon choix. J'ai choisi Maître Gims, artiste incontournable de la scène urbaine française.

Ce projet m'a permis de mettre en pratique mes compétences en HTML, CSS et PHP, avec une gestion des données musicales en JSON discographie complète, galerie d'albums, intégration Spotify et formulaire de contact.

Fonctionnalités développées
  • Page d'accueil avec intégration de players Spotify embarqués
  • Base de données discographique complète en JSON (60+ titres)
  • Galerie interactive avec upload d'images côté utilisateur
  • Formulaire de contact fonctionnel
  • Page partenaires et page crédits
  • Site responsive, compatible mobile
Technologies utilisées
HTML5 CSS3 PHP JSON JavaScript API Spotify
